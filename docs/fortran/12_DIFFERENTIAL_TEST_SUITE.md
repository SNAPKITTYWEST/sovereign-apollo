# Differential Test Suite — TypeScript Reference vs 1978 FORTRAN

> Phase 9 — `TypeScript Reference → Canonical Test Vector → FORTRAN → Compare` with explicit tolerances. Never declare equivalence via visual similarity.

## Canonical Test Vector

Source: `data/mission_timeline.json` (22 events, TIMELINE-001) → `fortran1978/mission_timeline.txt` (fixed-format, generated by `scripts/gen-fortran-timeline.ts`).

Each vector entry:

```
CMET*9  IMETSC  IVEH  IGUID  IALARM  ICOMM
000:00:00        0    0    0        0  0
...
102:38:22   369502    5   63     1202  0   ← 1202 fault
...
```

Both implementations consume this vector and produce `replay_out.txt` per `11_REPLAY_FORMAT`.

## Comparison Dimensions & Tolerances

| Dimension | TS Field | FORTRAN COMMON | Tolerance | Failure Class |
|-----------|----------|----------------|-----------|---------------|
| Mission time MET | `state.metSeconds` (INTEGER) | `IMETSC` | **0** (exact) | DIVERGENCE |
| MET string | `state.met` | `CMET` | exact string | DIVERGENCE |
| Vehicle state | `state.vehicle` flag | `IVEH` | exact | DIVERGENCE |
| Guidance mode | `state.guidanceMode` flag | `IGUID` | exact | DIVERGENCE |
| Throttle | `state.propulsion.throttle` (0..1) | `THROTT` | **1e-9** | NUMERICAL TOLERANCE |
| Alarm | `state.alarm` code | `IALARM` | exact | DIVERGENCE |
| Position (stub) | `state.position` km display (F7.1) | `POS/1000` | **1e-6** m (or 1e-3 km display) | TOLERANCE |
| Velocity | `state.velocity` m/s (F6.1) | `VEL` | **1e-6** m/s | TOLERANCE |
| Comm state | `state.comms` flag | `ICOMM` | exact | DIVERGENCE |
| Mass | `state.massKg` | `AMASS` | **1e-9** kg | TOLERANCE |
| Checksum chain | `finalHash` SHA256 hex | `ICHASH` MOD checksum | **not compared** — APPROXIMATION per 05_MAPPING (SHA vs MOD) — instead verify determinism separately |
| Event count | `frames.length` 22 | `NEVENT` 22 | exact | DIVERGENCE |

Tolerances chosen per 09 registry: double math same on both, Euler stub same, so tight.

## Test Cases (from `tests/fortran_diff.test.ts`)

1. **Timeline load** — TS `loadTimeline()` 22 events vs FORTRAN `LDTIML` 22 (verified via `test_timeline.exe` above — prints 22 lines correctly).
2. **Nominal replay 22 events** — all dimensions above per step.
3. **1202 fault at 102:38:22** — TS `FaultInjector` 1202 vs FORTRAN `FLTINS(0,...)` — both set `IALARM=1202` at event 11, phase resume.
4. **Throttle during P63** — TS `throttleCommand(5,0,15000)=0.94` vs FORTRAN `THROTC(5,0,15000)` — both clamp to 0.94 (940 permille).
5. **Determinism** — TS `verifyDeterminism()` twice same hash vs FORTRAN `REPVFY` twice same ICHASH (both pass).
6. **Comms state machine** — TS `CommsLink.update(-80)` → DATA vs FORTRAN `COMUPD(1,-80,...)` → DATA.

## First Divergence Detection

If mismatch, harness prints first N:

```
[DIFF] DIVERGENCE at step 10: TS THROTT 0.940 vs FORTRAN 0.939 diff 0.001 > tol 1e-9
```

Not just final hash — per-step canonical state diff.

## Classification

- **MATCH** — within tolerance
- **NUMERICAL TOLERANCE** — within 1e-9..1e-6 (acceptable APPROXIMATION)
- **DIVERGENCE** — outside tolerance or exact mismatch → block verification
- **UNTESTABLE** — not in canonical state (e.g., SHA vs MOD)
